ภาพของคุณ
อยู่บนเครื่องคุณ

PK PHOTO EDITOR ประมวลผลภาพบนอุปกรณ์ ไม่มีบัญชีผู้ใช้ โฆษณา หรือการอัปโหลดภาพไปแต่งบนเซิร์ฟเวอร์

ข้อมูลที่เก็บบนเครื่อง

รูปที่เลือกผ่าน Android Photo Picker จะถูกคัดลอกไว้ในพื้นที่ส่วนตัวของแอป พร้อมภาพย่อ สูตรแต่ง พรีเซ็ต ชื่อโปรเจกต์ ลำดับ/โปรด/ซ่อน/ถังขยะของโทน และการตั้งค่า การถอนแอปจะลบข้อมูลส่วนตัวนี้ ภาพที่ส่งออกไป MediaStore ยังคงอยู่จนกว่าคุณจะลบเอง

การเชื่อมต่อ

เมื่อคุณกดตรวจสอบหรือดาวน์โหลดอัปเดต แอปติดต่อแหล่ง HTTPS ที่ตั้งค่าไว้ ค่าเริ่มต้นคือ GitHub Releases ของ hertzscream/PK-PHOTO-EDITOR ไม่มีการแนบรูปหรือสูตรแต่งไปกับคำขอ ผู้ให้บริการเครือข่ายและ GitHub อาจเห็น IP และข้อมูลคำขอ HTTP ตามการทำงานของบริการนั้น

เว็บไซต์นี้

โฮสต์ด้วย GitHub Pages ไม่มีสคริปต์วิเคราะห์ผู้ชม คุกกี้ของแอป หรือฟอร์มรับภาพ นโยบายของ GitHub ใช้กับการเข้าใช้บริการ GitHub ด้วย

การติดตั้งอัปเดต

แอปตรวจ SHA-256 ชื่อแพ็กเกจ หมายเลขเวอร์ชัน และลายเซ็น APK ก่อนเปิดระบบติดตั้ง Android คุณเป็นผู้อนุญาตแหล่งติดตั้งและยืนยันการติดตั้ง
